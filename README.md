# АІС «ZLAGODA»

## Вимоги
- ОС Windows
- Python 3.10+
- Пакети Python (встановити нижче)

## Встановлення Python залежностей
```
pip install -r requirements.txt
```

## Запуск
```
python main.py                             # шукає zlagoda.accdb поряд із main.py
python main.py /шлях/до/файлу.accdb        # вказати інше розташування файлу .accdb
```

## Облікові записи за замовчуванням
| ID        | Пароль | Роль      |
|-----------|--------|-----------|
| E001      | e001   | Менеджер  |
| E002      | e002   | Касир     |
| E003      | e003   | Касир     |
| E004      | e004   | Касир     |
| E005      | e005   | Менеджер  |

Пароль можна змінити через кнопку «Змінити пароль» у бічній панелі.

## Структура проекту
```
zlagoda/
├── main.py              # точка входу
├── app.py               # вікно входу + головне вікно
├── requirements.txt
├── db/
│   └── database.py      # завантаження .accdb → SQLite in-memory
├── utils/
│   ├── theme.py         # кольори / шрифти
│   ├── widgets.py       # перевикористовувані компоненти
│   └── reports.py       # генерація PDF звітів
└── views/
    ├── employees.py     # Працівники
    ├── products.py      # Товари + Категорії
    ├── store_products.py# Товари у магазині
    ├── customers.py     # Карти клієнтів
    ├── checks.py        # Чеки + продаж
    └── statistics.py    # Статистика / запити
```

## Функціонал

### Менеджер
- CRUD: Працівники, Категорії, Товари, Товари у магазині, Карти клієнтів, Чеки
- Фільтри: за роллю, категорією, акційний/звичайний, датою, касиром, відсотком
- Пошук: за прізвищем, назвою, UPC
- Статистика: сума за касиром/всіма за період, кількість проданого товару, пошук за прізвищем, клієнти за відсотком
- Звіти: PDF-звіт з будь-якого списку

### Касир
- Перегляд: Товари у магазині, Товари, Карти клієнтів
- Пошук за UPC, назвою, прізвищем
- Додавання/редагування карток клієнтів
- Створення чеків (додавання товарів, застосування картки)
- Перегляд своїх чеків за день / за період
- Особистий профіль
